# Pooja Bazaar

Marketplace website for pooja items from local shops (Next.js 14 + Supabase + Vercel).

- Customers: browse shops, add to cart, order for pickup (order code) or free delivery above Rs 500
- Shopkeepers (/vendor): sign up, create shop, add items, accept and update orders

Setup: run `supabase/schema.sql` in Supabase SQL Editor, then set
`NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` (see `.env.example`).
